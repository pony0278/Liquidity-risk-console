本站蒐集什麼

本站是一個靜態網頁，不要求註冊、不蒐集姓名或電子郵件、沒有登入功能。 所有顯示的數據都來自公開資料源，與訪客無關。

伺服器記錄

本站託管於 GitHub Pages。GitHub 基於維運與資安需求，可能記錄訪客的 IP 位址與瀏覽器資訊， 這部分適用 GitHub 的隱私權聲明，本站無法存取這些記錄。

廣告與 Cookie

本站目前沒有投放廣告，也沒有載入任何廣告或分析用的第三方程式碼。

外部連結

本站包含指向 FRED、紐約聯準銀行等外部網站的連結。點擊後即適用該網站自己的隱私權政策。

免責聲明

本站為個人監測用的指標與傳導路徑整理，數值取自公開資料源並可能有時間落差或修正， 不構成投資建議。
